# TraceAI 愿景

## 一句话

把分散的 AI 对话，整理成**本地私密、可选公开**的可追溯知识地图。

## 核心信念

1. **默认私密** — 想法先留在本机，不是先上云。
2. **用户授权展示** — 每条想法需显式标记「可对外展示」才进入分享产物。
3. **最小出境** — 展示包可脱敏会话标题；完整备份由用户自行加密保管。
4. **行动导向** — 不只存档，要回答「继续哪条、哪条能变作品」。

## 分享产物（均由用户主动导出）

| 产物 | 包含内容 |
|------|----------|
| `traceai-backup-*.json` | 全部本机数据（私密） |
| `traceai-share-*.json` | 仅「可展示」想法 |
| `traceai-showcase-*.html` | 只读展示页，可单独部署 |
| Obsidian ZIP（可展示版） | 精选 Markdown |

## 长期（Phase 3+）

Obsidian + Claude Code + Git 本地 vault，与 TraceAI 展示层互补。
