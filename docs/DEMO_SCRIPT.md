# TraceAI · 30 秒录屏脚本（隐私 + 选择性展示）

**画面**：本机 `http://localhost:8080`（勿录真实 Claude 导出）

## 0:00–0:05 钩子

**口播**：「TraceAI：AI 对话知识地图，默认只存在你电脑里。」

**画面**：顶部绿色隐私条「本地优先」。

## 0:05–0:12 导入

**操作**：**加载示例 Demo** → 右侧出现想法卡片（左侧灰边 = 仅本地）。

## 0:12–0:18 选择性展示

**口播**：「想放进作品集的，勾选可对外展示。」

**操作**：勾选 1–2 条 **可对外展示** → 切 **可展示** Tab。

## 0:18–0:24 图谱

**操作**：**地图** Tab → 勾选 **地图仅显示可展示**（绿边节点）。

## 0:24–0:28 导出展示

**操作**：**预览展示** 或 **展示页 HTML**（强调：不含未勾选内容）。

## 0:28–0:30 收尾

**口播**：「完整对话从不自动上传——只有你点导出，才离开本机。」
