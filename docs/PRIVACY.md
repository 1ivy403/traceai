# TraceAI 隐私设计

## 原则

1. **默认本地**：对话解析、图谱、编辑均在浏览器完成；数据存入本机 `localStorage`。
2. **默认不展示**：每条想法默认「仅本地」，只有你勾选「可对外展示」的才会进入展示包。
3. **你决定何时出境**：没有任何自动上传；导出文件由你手动保存、手动分享。
4. **展示可脱敏**：导出展示包时，可隐藏原始会话标题（只保留想法正文与你写的下一步）。

## 数据存在哪

| 数据 | 位置 | 何时离开本机 |
|------|------|----------------|
| 完整知识库 | `localStorage`（键 `traceai-v2`） | 仅当你点击「导出本地备份」 |
| 展示内容子集 | 你生成的 `traceai-share-*.json` / `showcase.html` | 你主动发给他人或部署到 Pages |
| Claude 原始 JSON | 仅内存中解析，不写入 TraceAI 存储 | 不上传 |

## 推荐使用方式

- **日常**：`python3 -m http.server` 在本机打开，或用 VS Code Live Server。
- **作品集**：只导出「展示包」或「展示页」，不要上传含完整对话的备份。
- **GitHub Pages**：仅托管空壳 Demo + `sample/`，不要 push 个人 `conversations.json` 或 `.traceai-backup.json`。

## 不包含（v0.2 仍不做）

- 云端账号与同步
- 端到端加密备份（可自行用磁盘加密 + 私有仓库）
- 自动打码敏感词（请展示前人工检查）
